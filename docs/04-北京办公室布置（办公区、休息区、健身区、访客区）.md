# 北京办公室布置（办公区、休息区、健身区、访客区）

办公室按四个区来布置：办公区、休息区、健身区、访客区。面积和位置都还没定。办公区内另有 Jiehua 自用独立办公室。

办公区已明确：每人一套大号升降桌，有人在工位上时可以使用，并配套人体工学椅。按大桌面预留通道和椅后转身空间，不用单人小型升降桌。Jiehua 自用办公室要放置大号投影幕布和白板，与会议室分套；见 [Jiehua 自用办公室放置投影幕布和白板](10-Jiehua自用办公室放置投影幕布和白板.md)。

## 四个区

| 区域 | 已明确 |
| --- | --- |
| 办公区 | 每人一套大号升降桌，有人使用时可以使用；配套人体工学椅。按大桌面留通道和椅后转身空间。含 Jiehua 自用独立办公室（大号投影幕布 + 白板） |
| 休息区 | 布置大型电视一台（台位 T2）；面积、位置和其他设备尚未写 |
| 健身区 | 尚未写面积、位置和设备；默认不放大型电视 |
| 访客区 | 第三台大型电视（T3）可能落在访客等候；与「前台 / 公共区」是否同一处，以及其余设备尚未写 |

[办公室设备放置规划](office-equipment-plan.md) 已覆盖工位、Jiehua 自用办公室、会议、前台、网络、文印、茶水、入口和硬件实验室。休息区和健身区的其他设备不在那份规划里。多台大型电视见 [办公室布置多台大型电视](11-办公室布置多台大型电视.md)。访客区与规划中的「前台 / 公共区」是否同一处，还没对齐。

工位上的设备品类见 [北京办公室办公设备清单](06-北京办公室办公设备清单.md)。工位用显示器，不用大型电视。
