# 北京办公室布置（办公区、休息区、健身区、访客区）

办公室按四个区来布置：办公区、休息区、健身区、访客区。面积和位置都还没定。

目前只明确了办公区的一条规则：每个工位配一套升降桌，有人在工位上时可以使用。

## 四个区

| 区域 | 已明确 |
| --- | --- |
| 办公区 | 每个工位一套升降桌，有人使用时可以使用 |
| 休息区 | 尚未写面积、位置和设备 |
| 健身区 | 尚未写面积、位置和设备 |
| 访客区 | 尚未写面积、位置和设备 |

[办公室设备放置规划](office-equipment-plan.md) 已覆盖工位、会议、前台、网络、文印、茶水、入口和硬件实验室。休息区和健身区不在那份规划里。访客区与规划中的「前台 / 公共区」是否同一处，还没对齐。

工位上的设备品类见 [北京办公室办公设备清单](06-北京办公室办公设备清单.md)。
