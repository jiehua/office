# 办公室布置多台大型电视

本文件规划办公室里多台大型电视怎么放。它覆盖会议室、休息区和可选的访客等候或第二间会议室的大屏，不覆盖工位上的电脑显示器。台数、位置、挂装方式和状态改这里。

[办公室设备放置规划](office-equipment-plan.md) 只保留入口，避免两处各写一套。四区划分见 [北京办公室布置](04-北京办公室布置（办公区、休息区、健身区、访客区）.md)。工位显示器仍以 [办公设备清单](06-北京办公室办公设备清单.md) 和总规划工位区为准。

这是放置规划，不是已经批准的采购。房间号还没定，下表「建议位置」先写相对关系，房间确定后改成真实房间和台位编号。

状态用总规划里的四个词：规划中、已到位、已放置、待移除。

## 选型

按「大型电视」规划：会议室和休息区用的墙挂或可移动落地大屏，不是工位 27 寸显示器，也不是投影幕布作为默认方案。可移动幕布只作为临时备选，不计入下表台数，除非把某一行数量从电视改成幕布并写进变更记录。

这是体量倾向，不是已经批准的采购。具体品牌、英寸和是否商用面板还没定。

## 放在哪里

大型电视放在需要多人一起看的公共空间，不进工位桌面，不进硬件实验室、网络间、文印角和茶水间操作台。

- 主会议室：入门正对的短边墙面，承接总规划里原来的「显示屏或投影」。
- 休息区（茶歇）：沙发或拼接桌对面的墙面，供休息和非正式分享。
- 访客等候或第二间小会议室：第三台的落点，等分区确认后再写死房间；确认前仍占台位编号，不挪去工位。
- 不挡疏散门、消防栓和通道。前方留出观看距离，线缆不上地横穿。
- 屏幕不正对强光窗；避不开时加遮光，不把电视贴在西晒玻璃旁。

健身区默认不放大型电视。若以后要加，先改本表，不与休息区共用一台。

## 先放多少

起步按 3 台大型电视规划：一台服务正式会议，一台服务休息区，一台留给访客等候或第二间会议室。工位显示器不计入这 3 台。

| 设备 | 数量 | 用途 | 建议位置 | 电源 / 网络 | 状态 | 备注 |
| --- | --- | --- | --- | --- | --- | --- |
| 大型电视 | 1 | 主会议显示、投屏、远程会议画面 | 主会议室短边墙，台位 T1 | 墙面插座 + 有线网络 | 规划中 | 与视频会议终端、无线投屏器同区；底边高度不挡坐姿视线 |
| 大型电视 | 1 | 休息区茶歇、非正式分享 | 休息区沙发或拼接桌对面墙，台位 T2 | 墙面插座；有线网络优先 | 规划中 | 默认墙挂；确认结构承重前可用合格落地支架过渡 |
| 大型电视 | 1 | 访客等候或第二间小会议室 | 访客区等候墙或小会议室短边墙，台位 T3 | 墙面插座；网络按落点接入办公网或访客展示内容源 | 规划中 | 分区未定时先不采购就位；编号保留，落点确认后改「建议位置」 |
| 无线投屏器 | 按电视台数 | 笔记本投屏 | 各台屏幕旁或同区桌面 | 与对应电视同一网络 | 规划中 | 主会议室可与总规划里的投屏器合并，不强制双套 |
| 视频会议终端 | 1 | 远程会议 | 仅 T1 屏幕上方或下方 | 有线网络 | 规划中 | 休息区和 T3 默认不配会议终端，除非改本表 |

T1、T2、T3 是台位编号，不是型号。品牌和英寸确定后写进备注，编号不改。

## 挂装和观看距离

优先墙挂；墙体承重或埋件未确认前，可用标明承重的落地支架，支架不侵占通道。

| 项目 | 要求 |
| --- | --- |
| 安装方式 | 默认墙挂；过渡期可用落地支架，脚轮在到位后锁止 |
| 底边高度 | 会议室：坐姿视线不被桌沿和前排挡；休息区：沙发坐姿中心约对屏幕中线 |
| 前方净空 | 屏幕前不放高于视线的柜体；通道仍不小于 1.2 m |
| 观看距离 | 按到货英寸留出大致距离，前排不贴脸、后排不吃力；具体按房间深度微调 |
| 线缆 | 电源和 HDMI / 网线进墙内或线槽，不沿地面横穿通道 |
| 防晒与反光 | 不正对无遮光的强光窗；玻璃幕墙侧优先加窗帘后再定挂点 |
| 叠放与拼接 | 默认单屏。要做拼接墙时先改本表，并单独确认支架和信号方案 |

## 电源和网络

大屏待机加音响时功率通常远低于加热类设备，但仍按每台独立取电规划，具体回路由电工按到货铭牌核定。

- 每台电视一个墙面插座，不与微波炉、冰箱、3D 打印机、CNC、咖啡机器人串在同一块排插上。
- 电视不接 UPS。UPS 只带网络和门禁；会议终端若需短暂保电，单独说明，不把整机电视挂上 UPS。
- 主会议室（T1）优先有线网络到电视或会议终端；投屏器与终端同一网段。
- 休息区（T2）有线优先；暂时用无线时走办公网，不把访客随意接入内部会议设备。
- T3 若在访客区只播公示或欢迎内容，信号源与办公内网隔离方式待确认后再接。
- 遥控与 HDMI 收纳在屏幕旁盒内，不散落沙发和会议桌。

## 和各区其他设备的关系

| 相邻设备 / 区域 | 放置关系 |
| --- | --- |
| 工位显示器 | 仍是每人桌面屏，默认 27 寸；不改成大型电视，也不把 T1–T3 挪到工位 |
| 会议桌、会议椅、白板 | 白板在 T1 相邻墙，不挡屏幕和空调出风；桌面少留固定线缆 |
| 休息区沙发、拼接桌 | 面对 T2；茶几不挡屏幕下部通风口 |
| 咖啡机器人、胶囊咖啡机 | 在茶水或休息区边柜，不挡 T2 观看区。咖啡机器人是否采购见 [07](07-办公室可以考虑部署一台带机械臂咖啡机器人.md) |
| 动感单车等健身设备 | 在健身区；默认不面向大型电视。健身区若要加屏，另开台位 |
| 3D 打印机、桌面 CNC | 只在硬件实验室，见 [08](08-办公室放置多台3D打印机.md)、[09](09-办公室放置一套桌面CNC设备.md)；实验室不放大型电视 |
| 前台、快递架 | 不挡 T3 若落在访客等候墙时的观看和通行 |

## 内容与开关机

- 每台贴标签：台位编号（T1–T3）、区域、负责人。标签和本表一致。
- 主会议室（T1）会议结束后退出投屏账号，不要长期停在未锁的桌面。
- 休息区（T2）默认可本地投屏；是否常驻信息看板待确认，确认前不当作广告机 24 小时亮屏。
- T3 在访客区时，不显示未脱敏的内部看板。
- 夜间或周末无人时，电视关机或切断插座取电，不长期亮屏无人值守。
- 移位、换机、改数量，都改本表，并在文末变更记录补一行。

## 放置时一起检查

- [ ] T1–T3 台位与房间落点已对齐，或 T3 落点仍写在待确认且未强行采购就位
- [ ] 墙挂承重或落地支架合格；屏幕前通道不小于 1.2 m
- [ ] 每台独立墙插；线缆进线槽，不横穿通道
- [ ] T1 与会议终端、投屏器同区；休息区和访客区未误接需隔离的内部信号
- [ ] 不挡疏散门、消防栓；不强光直射屏幕
- [ ] 标签已贴，台位编号与本表一致
- [ ] 工位区没有误放大型电视；实验室、网络间、文印角没有大型电视

## 待确认

- [ ] 主会议室、休息区、访客区或第二间会议室的房间号和墙面
- [ ] 最终台数是否就是 3。增减时改上表，不另起一份清单
- [ ] T3 落在访客等候还是第二间小会议室
- [ ] 各台英寸、是否商用面板、品牌和型号
- [ ] 墙体能否打孔挂装；不能时落地支架型号与承重
- [ ] 电工确认插座位置和回路
- [ ] 休息区是否允许常驻信息看板，以及夜间是否必须断电
- [ ] T3 在访客区时的内容源与网络隔离方式
- [ ] 可移动幕布是否替代某一台电视；若替代，改对应行并记变更记录
