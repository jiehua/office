# 办公室设备放置规划

本文件是办公室设备放置的规划来源。多台 3D 打印机的台数、位置和选型见 [办公室放置多台 3D 打印机](08-办公室放置多台3D打印机.md)。桌面 CNC 的台数、位置和选型见 [办公室放置一套桌面 CNC 设备](09-办公室放置一套桌面CNC设备.md)。Jiehua 自用办公室的大号投影幕布和白板见 [Jiehua 自用办公室放置投影幕布和白板](10-Jiehua自用办公室放置投影幕布和白板.md)。多台大型电视的台数、位置和挂装见 [办公室布置多台大型电视](11-办公室布置多台大型电视.md)。其余设备的新增、移动、替换和报废，都直接改这里，再提交到 GitHub。远程仓库与这份文件保持同步，以 `main` 上的最新版本为准。

## 怎么更新

1. 在对应区域的表格里改数量、位置或状态。
2. 在文末「变更记录」补一行：日期、改了什么、谁改的。
3. 提交并推送到 GitHub。合并进 `main` 后，这份规划即是当前有效版本。

状态只用下面四个词：

| 状态 | 含义 |
| --- | --- |
| 规划中 | 已列入计划，尚未采购或尚未到位 |
| 已到位 | 设备已到货，还没放到指定位置 |
| 已放置 | 已按本文件放到指定位置，可正常使用 |
| 待移除 | 计划撤走、替换或报废 |

## 区域

先按使用场景划分放置区域。具体房间号确定后，把「位置」列改成真实房间或工位编号。

休息区、健身区的划分见 [北京办公室布置](04-北京办公室布置（办公区、休息区、健身区、访客区）.md)。这两区的面积和其他设备还没写，本表不单列；休息区的大型电视见 [11](11-办公室布置多台大型电视.md)。访客区与下表「前台 / 公共区」是否同一处，也见那份布置文档的待确认；访客等候若放第三台电视，同样只在 11 维护。

| 区域 | 用途 | 放置重点 |
| --- | --- | --- |
| 工位区 | 日常办公 | 每人一套大号升降桌 + 人体工学椅，走线不挡通道 |
| Jiehua 自用办公室 | 独立办公、小范围投屏讨论 | 大号投影幕布、白板；与会议室分套，见专项文档 |
| 会议室 | 讨论、远程会议 | 显示、投屏、拾音，桌面少留固定线缆 |
| 前台 / 公共区 | 接待、等候、打印取件 | 访客可见、不影响通行 |
| 网络间 | 交换机、路由、弱电 | 独立电源、通风、上锁 |
| 文印角 | 打印、扫描、装订 | 靠近纸张耗材，远离饮水机 |
| 茶水间 | 饮水、加热、冷藏 | 独立水路和插座，与文印分开 |
| 入口 | 门禁、监控 | 覆盖出入口，录像设备放网络间 |
| 硬件实验室 | 3D 打印、桌面 CNC、测控 | 与工位隔开，独立电源和通风 |

## 工位区

按一个工位一套来计。人数确定后，把数量改成实际人头，并在备注里写工位编号。

电脑、显示器、大号升降桌和人体工学椅的品类见 [北京办公室办公设备清单](06-北京办公室办公设备清单.md)。每人一套大号升降桌，配套人体工学椅，不用单人小型升降桌。

| 设备 | 数量 | 建议位置 | 电源 / 网络 | 状态 | 备注 |
| --- | --- | --- | --- | --- | --- |
| 大号升降桌 | 与工位数相同 | 靠窗优先；按大号台面排布，通道宽度不少于 1.2 m，椅后预留转身空间 | 每桌 1 个桌面插座组 | 规划中 | 每人一套；含走线孔；不用单人小型升降桌 |
| 人体工学椅 | 与工位数相同 | 每张升降桌配一把 | 无 | 规划中 | 与大号升降桌成套 |
| 显示器 | 与工位数相同 | 桌面居中，下沿约与视线平齐 | 桌下插座 | 规划中 | 默认 27 寸；设计岗可双屏 |
| 笔记本扩展坞 | 与工位数相同 | 显示器后方或桌下 | 有线网络优先 | 规划中 | 一根上行线到主机 |
| 键鼠 | 与工位数相同 | 桌面 | 优先无线接收器收进扩展坞 | 规划中 | |
| 台灯 | 与工位数相同 | 非主手一侧 | 桌面插座 | 规划中 | 避免直射屏幕 |
| 桌下理线槽 | 与工位数相同 | 桌下后沿 | — | 规划中 | 电源与网线分开 |

## 硬件实验室

实验室机械臂、视觉系统和 NI 测控以 [北京硬件实验室设备清单](03-北京硬件实验室设备清单.md) 为准。多台 3D 打印机的台数、选型、台面、通风和状态见 [办公室放置多台 3D 打印机](08-办公室放置多台3D打印机.md)。桌面 CNC 的台数、选型、台面、集尘和状态见 [办公室放置一套桌面 CNC 设备](09-办公室放置一套桌面CNC设备.md)。上述专项不在本文件重复。

打印机与 CNC 都放硬件实验室，不进工位、会议、茶水、文印和访客区；二者分台，也不与视觉、NI 测控共用一张台。

## 放置时一起检查

- 每个固定设备都有自己的插座，不把打印机、冰箱、微波炉串在同一块排插上。
- 网线与强电平行时拉开距离，工位网线进理线槽，不沿地面横穿通道。
- 机柜、门禁、视频会议终端接到 UPS；空调、冰箱、打印机不接 UPS。
- 通道、消防栓、疏散门前不放设备。
- 设备贴标签：名称、区域、负责人。标签文字和本表「建议位置」一致。
