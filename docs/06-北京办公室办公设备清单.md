# 北京办公室办公设备清单

每个工位一套办公设备。本文件只确定品类：电脑、显示器、单人小型升降桌、人体工学椅。类型、规格和数量都还没定。

放到哪个位置、怎么走线，以 [办公室设备放置规划](office-equipment-plan.md) 的工位区为准。人数确定后，规划里的数量改成实际人头。
