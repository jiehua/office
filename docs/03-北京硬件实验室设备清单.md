# 北京硬件实验室设备清单

硬件实验室列入五类设备。本文件只记录要哪些类别。数量、型号、预算和房间号都还没定。

3D 打印机的台数、选型和放法只维护在 [办公室放置多台 3D 打印机](08-办公室放置多台3D打印机.md)。桌面 CNC 的台数、选型和放法只维护在 [办公室放置一套桌面 CNC 设备](09-办公室放置一套桌面CNC设备.md)。其余设备放在哪，以 [办公室设备放置规划](office-equipment-plan.md) 的硬件实验室一节为入口。

## 设备

| 设备 | 已明确 | 另见 |
| --- | --- | --- |
| 3D 打印机 | 列入实验室 | 台数、选型、台面、通风只改 [08](08-办公室放置多台3D打印机.md) |
| 桌面 CNC | 列入实验室 | 台数、选型、台面、集尘只改 [09](09-办公室放置一套桌面CNC设备.md)；与打印机分台 |
| 实验室机械臂 | 列入实验室 | 工作范围不进入打印机与 CNC 前方操作区，见 [08](08-办公室放置多台3D打印机.md)、[09](09-办公室放置一套桌面CNC设备.md) |
| 视觉系统 | 采用 NI 的设备和解决方案 | 与打印机、CNC 分台，见 [08](08-办公室放置多台3D打印机.md)、[09](09-办公室放置一套桌面CNC设备.md) |
| NI 测控主机 | 列入实验室 | 与视觉系统是否同一套，见下方待确认 |
