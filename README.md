# office

北京办公室的筹建记录都在 [`docs/`](docs/)。先看选址和分区，再看设备放在哪。

选址（[02](docs/02-北京办公室选址.md)）定区域和楼宇条件。布置（[04](docs/04-北京办公室布置（办公区、休息区、健身区、访客区）.md)）划分办公、休息、健身、访客，并规定每人一套大号升降桌。工位设备的品类在 [06](docs/06-北京办公室办公设备清单.md)，数量和位置在 [设备放置规划](docs/office-equipment-plan.md)。Jiehua 自用办公室的大号投影幕布和白板只改 [10](docs/10-Jiehua自用办公室放置投影幕布和白板.md)。硬件实验室的设备类别在 [03](docs/03-北京硬件实验室设备清单.md)；打印机的台数、位置和选型只改 [08](docs/08-办公室放置多台3D打印机.md)；桌面 CNC 的台数、位置和选型只改 [09](docs/09-办公室放置一套桌面CNC设备.md)。咖啡机器人（[07](docs/07-办公室可以考虑部署一台带机械臂咖啡机器人.md)）仍是一项考虑。员工 AI 工具（[05](docs/05-企业员工配置-AI工具.md)）与房间无关。

## 文档格式约定

- 每份议题文档开头保留 GitHub issue 元数据。
- 正文先写已经明确的结论。同类项目用表格并列。相关文档互相链接，同一事实只在一处维护。
- 尚未明确的信息写在「待确认」，不臆测补全。
- 01 是已关闭且不属于办公室筹建的存档。索引里 01–07 的「已关闭」表示 GitHub issue 已关闭；没写完的事项仍以各文件的「待确认」为准。
- 08、09、10 和设备放置规划是可执行规划，后续修改记在各自的变更记录。
